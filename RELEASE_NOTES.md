# Inventory BackPack for Multiplayer — v1.0.0.0

Initial public release candidate for Farming Simulator 25 (PC).

**Included**
- Personal 15-slot backpack (5 columns × 3 rows).
- Mouse and keyboard navigation; quick item storage and retrieval.
- Dedicated multiplayer and per-savegame player inventory metadata.
- Portable-item validation to reject normal vehicles and implements.
- Item-image display and matching-item counts.

**Controls:** `I` open/close, `Y` store item, arrows select, `Enter` drop, `Esc` close.

**Install:** Download `FS25_InventoryBackPack_for_Multiplayer.zip` attached to this release and place it, without unpacking, in your FS25 mods directory. Dedicated-server clients and server need the same version.

**Note:** Test first with a backup savegame. Source-mod item compatibility varies. The final v1.0.0.0 metadata changes have not yet been verified with a fresh GIANTS TestRunner result.
